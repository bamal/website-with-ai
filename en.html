The final result

What we want to build

A simple, clean, durable website. Just a storefront that represents you and invites people to get in touch.

A site on your own domain

A domain name with your name or brand, with HTTPS activated automatically. The only recurring cost: ~$10 per year with Cloudflare.

A clear homepage

Your message, your offer, your bio and a call to action. The visitor understands who you are and how to contact you in a few seconds.

A guide or resource page

A PDF or useful content page that shows your expertise. The link is direct.

Why this method?

Because an effective site doesn't need complicated automation.

You can add Calendly for bookings, a simple contact form, or a WhatsApp link. The rest happens in the real conversation. Fewer tools = fewer things that break.

Day 1

Foundations & build

We lay the groundwork: your Business Brain, your content, your design and your code.

1

Fill in your Business Brain

Clarify your offer, your ideal client and your voice before writing a line of code.

45-60 min
Simple explanation: before building a house, you draw the plans. The Business Brain is your plan.

Use the Business Brain document to answer these questions:

1
Who you help (segment, problem, situation).
2
What concrete result you bring them.
3
How you differ from other coaches / advisors.
4
What are your 1 to 3 main services or offers.
5
On which platforms you want to be seen and heard.

🌐 View the Business Brain online

Why this document is useful: it's the single source of truth for your business, your brand and your growth strategy. You share it with your AI assistant, your strategist or your team so they have the full context on who you are, what you do and where you're going.

Watch out for Claude Code's permission requests: while you fill in your Business Brain, Claude Code will often ask for permission to read or modify folders and documents. Click Yes / Allow every time. This lets it write directly into your files and saves you manual copy-paste.

5

Create a GitHub token for Claude Code

Allows Claude Code to push changes automatically.

10 min
Simple explanation: a token is a key you give Claude Code so it can modify your repo without you going to GitHub for every change.

1
In GitHub, go to Settings → Developer settings → Personal access tokens → Tokens (classic).
2
Click Generate new token (classic).
3
Give it a name, e.g. Claude Code site, and check the repo permission.
4
Generate the token and copy it immediately.
5
Give this token to Claude Code with this prompt: "Connect my amal-site GitHub repo to Claude Code with this token."
✅
Result: for every code change, Claude Code sends the changes to GitHub automatically. You no longer need to drag and drop files manually.
🔐
Validation at every change: after giving the token, Claude Code will ask you each time if it can modify your GitHub repo. You tell it Yes, and it pushes the changes on its own. This saves a lot of headaches and you don't have to log in to GitHub manually for every update.

Step 6.5: automatic deployment via Claude Code with a Vercel token (optional)

This method allows Claude Code to create the project, connect the domain and trigger deployment without you clicking in the Vercel interface.

1
Go to vercel.com/account/tokens.

Go to Account Settings → Tokens to create a new Vercel key.

2
Click Create Token and give it a name, e.g. Claude Code deploy.
3
Check the permissions: Projects (Read/Write), Deployments (Read/Write) and Domains (Read/Write).
4
Copy the token and give it to Claude Code with this prompt: "Here's my Vercel token: PASTE_TOKEN. Deploy my site automatically."
5
Claude Code runs the Vercel deployment command line for you. You don't have to type anything yourself.

Example of the message you'll receive when Vercel has finished deploying.

✅
Result: the site is created and deployed directly from the Claude Code conversation. Even if you haven't bought a domain name yet, Vercel gives you a free temporary link, for example: https://asmaehajji-website-31dsg1c6k-asmae1.vercel.app/fr. Future changes can also be pushed and redeployed the same way.
The beauty of the system

Every change deploys itself.

Thanks to the added tokens, Claude Code automatically sends every change to GitHub. Vercel receives the update from GitHub and redeploys automatically. You have no manual operations to perform: everything syncs in the background.

⚠️
Security: revoke the Vercel token as soon as setup is complete. Never leave this key active longer than necessary.

Step 7.5: automatically connect Cloudflare and Vercel with a Cloudflare token (optional)

If you want Claude Code to configure the DNS records to connect your Cloudflare domain to Vercel without manual intervention, you need a Cloudflare token with the right permissions.

1
In Cloudflare: click your avatar → My Profile → API Tokens → Create Token.
2
Use the custom template and check permissions: Zone (Read) and DNS (Edit).
3
Restrict the token to your domain's zone for better security.
4
Copy the token and give it to Claude Code with this prompt: "Here's my Cloudflare token: PASTE_TOKEN. Connect my domain [yourdomain.com] to my Vercel project and configure DNS automatically."

Example: Cloudflare asks to create an API token to connect the domain to Vercel.

Claude Code executes deployment and redeployment automatically.

✅
Result: Claude Code can add the A and CNAME records in Cloudflare, temporarily disable the proxy while Vercel validates the domain, then deploy and redeploy the site automatically every time you make a change without you having to intervene.
⚠️
Security: revoke the Cloudflare token once the domain is connected. Don't leave it active unnecessarily.
Advice: your personal name is the best domain. It will survive all positioning changes.

Remember

The 5 rules to avoid mistakes

1. GitHub before Vercel

Vercel connects to your GitHub account. You can't import a repo before creating it.

2. Deploy before connecting the domain

The domain must point to a site that already exists. Otherwise Vercel has nothing to display.

3. Wait for DNS propagation

Between adding DNS records and the moment the site responds on your domain, it can take 5 minutes to a few hours.

4. Test before announcing

Open the site on your phone, click every button, check your professional redirect. Don't share a broken link.

5. Fewer tools = fewer risks

Every added tool is a potential failure point. Start with GitHub + Vercel + Cloudflare. Add the rest only if you really need it.

Frequently asked questions

The most common blockers

Do I really need Claude Code + Ollama?

You can use Claude Code alone or with Ollama/Kimi locally (free). The advantage of local is that everything stays on your machine. The advantage of the cloud is power and simplicity: count about $20/month for that option. If Kimi isn't available locally, replace it with an Ollama-compatible model like Llama 3 or Mistral.

How do I install Claude Code, Ollama and use Kimi?

1. Claude Code: go to the official documentation https://code.claude.com/docs/en/setup. On Windows, open a PowerShell terminal and run this command:

irm https://claude.ai/install.ps1 | iex

Example: installing Claude Code in a Windows PowerShell terminal.

2. Add Claude Code to PATH: after installation, Windows needs to know where to find Claude Code so you can launch it from any folder. If the claude command is not recognized, add its installation folder to the PATH environment variable.

1
Open the Start menu and type environment variables.
2
Click Edit the system environment variables.
3
At the bottom, click Environment Variables....
4
In the User variables section, select Path then click Edit....
5
Click New and paste the path where Claude Code was installed, for example: C:\Users\YOUR_ACCOUNT\AppData\Local\AnthropicClaude\bin.
6
Confirm with OK on all windows, then restart PowerShell.
7
Verify by typing: claude --version.

3. Ollama (local models): download Ollama from ollama.com and install it. Ollama lets you run language models locally without sending your data to the cloud.

After installation, verify everything is installed by typing these two commands in PowerShell:

ollama --version claude --version

If both commands return a version number, installation is correct. Otherwise, check PATH or reinstall.

4. Launch Claude Code with Ollama: once Ollama is installed, open a PowerShell terminal and launch Claude Code in local mode with the command:

ollama launch claude

This command starts Claude Code connected to your local Ollama instance.

5. Choose Kimi from the list: after launching, a list of available models appears. Use the ↑ ↓ arrow keys to scroll down the list, select Kimi, then press Enter to choose it.

Important: use the arrow keys to scroll down and select Kimi in the model list.

Does Cloudflare really cost only $10 per year?

Yes, for a standard .ca or .com domain, Cloudflare often shows a price around $10 per year (taxes not included depending on your province). Vercel, GitHub and Calendly remain free at this usage level.

Can I still add a contact form?

Yes. The simplest way without a backend: a message link that opens the visitor's email app directly with a prefilled subject. Example: contact@yourdomain.ca?subject=Contact%20request. If you want a real form, you can add a service like Formspree later.

How do I sell services online securely?

The simplest and most secure solution is to use a Stripe Payment Link. You create a payment link in Stripe, then embed it in a button on your site. It's fast, reliable, and you don't need to code a payment system.

What if I want to add a blog later?

You can. But start with a single homepage. A blog requires a more complex structure. Once your site is running, you can migrate to a static site generator or add HTML pages manually.

How long does it really take?

If you already have your Business Brain and content, the site can be online in one day. If starting from zero, count 2 to 4 hours per day for 3 days. The technical part (GitHub + Vercel + Cloudflare) only takes an hour once you know the steps.

Where is my website source code?

Your website source code is on your computer, in the JavaScript project folder created by Claude Code. Claude Code already has access to it: that's why it asks for your permission every time it wants to read or modify a file. You tell it Yes, and it makes the change directly on your machine. When everything is ready, it also pushes the files to GitHub to put them online.
