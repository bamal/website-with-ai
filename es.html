De la idea al sitio web.

Un método para construir un sitio web profesional en tu propio dominio, sin herramientas complejas ni automatización innecesaria. No necesitas ser desarrolladora. Solo seguir los pasos en orden.

El resultado final

Lo que queremos construir

Un sitio web simple, limpio y duradero. Solo una vitrina que te represente y invite al contacto.

Un sitio en tu propio dominio

Un nombre de dominio con tu nombre o marca, con HTTPS activado automáticamente. El único costo recurrente: ~10 $ al año con Cloudflare.

Una página de inicio clara

Tu mensaje, tu oferta, tu biografía y un llamado a la acción. La visitante entiende quién eres y cómo contactarte en pocos segundos.

Una página guía o recurso

Un PDF o página de contenido útil que demuestra tu expertise. El enlace es directo.

¿Por qué este método?

Porque un sitio eficaz no necesita automatización complicada.

Puedes agregar Calendly para reservas, un formulario de contacto simple o un enlace de WhatsApp. El resto ocurre en la conversación real. Menos herramientas = menos cosas que se rompen.

Cimientos y construcción

Sentamos las bases: tu Business Brain, tu contenido, tu diseño y tu código.

1

Completar tu Business Brain

Clarifica tu oferta, tu cliente ideal y tu voz antes de escribir una línea de código.

45-60 min
Explicación simple: antes de construir una casa, se dibujan los planos. El Business Brain es tu plano.

Usa el documento Business Brain para responder estas preguntas:

1
A quién ayudas (segmento, problema, situación).
2
Qué resultado concreto les aportas.
3
En qué te diferencias de otras coachs / asesoras.
4
Cuáles son tus 1 a 3 servicios u ofertas principales.
5
En qué plataformas quieres ser vista y escuchada.

Por qué este documento es útil: es la única fuente de verdad para tu negocio, tu marca y tu estrategia de crecimiento. Lo compartes con tu asistente IA, tu estratega o tu equipo para que tengan el contexto completo sobre quién eres, qué haces y hacia dónde vas.
🔁
Presta atención a las solicitudes de Claude Code: mientras completas tu Business Brain, Claude Code te pedirá permiso para leer o modificar carpetas y documentos. Haz clic en Yes / Allow cada vez. Esto le permite escribir directamente en tus archivos y evitarte copiar y pegar manualmente.

Definir la identidad visual con Claude Code

Antes de programar, fija la apariencia de tu marca: logo, favicon, fuentes y colores.

30 min
Explicación simple: la identidad visual es el atuendo de tu marca. Si está clara antes, el sitio se construye mucho más rápido.

Dale este prompt a Claude Code señalando tu Business Brain:

"Usa el documento Business Brain en esta ruta de mi computadora: C:/Users/boukh_2njb9wx/OneDrive/Documents/Claude/Projects/CLAUDE/coaching/active/website-sans-funnel/business-brain/business-brain.pdf Define mi identidad visual según mis preferencias y posicionamiento descritos en el Business Brain. Propón: - un logo simple para mi sitio web, - un favicon, - 2 fuentes principales compatibles con la web, - 2 colores principales para mi sitio, - una dirección gráfica coherente con mi audiencia y oferta. Hazlo como una diseñadora gráfica web senior, de manera profesional." > Consejo: si Claude Code tiene dificultad para leer el PDF, dale la ruta del archivo business-brain.html, que es texto legible.
✅
Resultado: una mini guía de marca (logo, favicon, fuentes, colores) que podrás reutilizar para tu sitio, PDFs y publicaciones.

5

Crear un token de GitHub para Claude Code

Permite que Claude Code envíe los cambios automáticamente.

10 min
Explicación simple: un token es una llave que le das a Claude Code para que pueda modificar tu repo sin que vayas a GitHub en cada cambio.

1
En GitHub, ve a Settings → Developer settings → Personal access tokens → Tokens (classic).
2
Haz clic en Generate new token (classic).
3
Dale un nombre, ej. Claude Code site, y marca el permiso repo.
4
Genera el token y cópialo inmediatamente.
5
Dale este token a Claude Code con este prompt: "Conecta mi repo amal-site de GitHub a Claude Code con este token."
✅
Resultado: en cada cambio de código, Claude Code envía los cambios a GitHub automáticamente. Ya no necesitas arrastrar y soltar archivos manualmente.
🔐
Validación en cada cambio: después de dar el token, Claude Code te preguntará cada vez si puede modificar tu repo de GitHub. Dile Yes, y él empuja los cambios solo. Esto ahorra muchos dolores de cabeza y no tienes que iniciar sesión en GitHub manualmente en cada actualización.

Crear una cuenta en Vercel

Alojamiento gratuito y simple.

5 min

Ve a vercel.com/signup.
2
Elige Continue with GitHub para vincular tu cuenta automáticamente.

🔗
Por qué vincular GitHub: cuando tu cuenta de Vercel está conectada a GitHub, Vercel puede acceder directamente al repo de tu sitio. Esto facilita la importación y el despliegue automático en cada cambio.
Paso 6.3: instalar la integración de GitHub en Vercel
3
Una vez conectado a Vercel, haz clic en tu avatar → Settings → Integrations.
4
Verifica que la integración GitHub esté instalada.
5
Si te lo piden, autoriza a Vercel para acceder a tus repositorios.

✅
Resultado: Vercel ahora tiene permiso para leer el repo de tu sitio en GitHub. Sin este paso, Vercel no podrá importar tu proyecto.
Paso 6.4: importar el proyecto de GitHub a Vercel
6
En Vercel, haz clic en Add New → Project.
7
Selecciona el repo de tu sitio web (amal-site).
8
Haz clic en Import y luego en Deploy.

Después de 1 a 2 minutos, obtienes un enlace temporal:

https://tu-repo.vercel.app
✅
Abre este enlace en tu navegador. Debes ver tu sitio.
Paso 6.5: despliegue automático mediante Claude Code con un token de Vercel (opcional)

Este método permite que Claude Code cree el proyecto, conecte el dominio y active el despliegue sin que hagas clic en la interfaz de Vercel.

1
Ve a vercel.com/account/tokens.

Ve a Account Settings → Tokens para crear una nueva clave de Vercel.

2
Haz clic en Create Token y dale un nombre, ej. Claude Code deploy.
3
Marca los permisos: Projects (Read/Write), Deployments (Read/Write) y Domains (Read/Write).
4
Copia el token y dáselo a Claude Code con este prompt: "Aquí está mi token de Vercel: PASTE_TOKEN. Despliega mi sitio automáticamente."
5
Claude Code ejecuta el comando de despliegue de Vercel en línea de comandos por ti. No tienes que escribir nada tú misma.

Ejemplo del mensaje que recibirás cuando Vercel haya terminado el despliegue.

✅
Resultado: el sitio se crea y se despliega directamente desde la conversación con Claude Code. Aunque aún no hayas comprado un dominio, Vercel te da un enlace temporal gratuito, por ejemplo: https://asmaehajji-website-31dsg1c6k-asmae1.vercel.app/fr. Los cambios futuros también pueden enviarse y redesplegarse de la misma manera.
La belleza del sistema

Cada cambio se despliega solo.

Gracias a los tokens añadidos, Claude Code envía automáticamente cada cambio a GitHub. Vercel recibe la actualización desde GitHub y vuelve a desplegar automáticamente. No tienes ninguna operación manual que realizar: todo se sincroniza en segundo plano.

⚠️
Seguridad: revoca el token de Vercel en cuanto termine la configuración. Nunca dejes esta clave activa más tiempo del necesario.
7

Comprar tu nombre de dominio en Cloudflare

El único costo: unos 10 $ al año.

10 min
1
Ve a cloudflare.com y crea una cuenta. El registro es fácil mediante tu cuenta de GitHub.

Regístrate en Cloudflare haciendo clic en Continue with GitHub.

2
En el panel, haz clic en Registrar → Register domains.
3
Busca tu nombre (por ejemplo asmaehajji.com).
4
Añádelo al carrito y paga. El precio es de unos 10 $ al año.

Ejemplo: búsqueda de asmaehajji.com en el registrador de Cloudflare.

Paso 7.5: conectar Cloudflare y Vercel automáticamente con un token de Cloudflare (opcional)

Si quieres que Claude Code configure los registros DNS para conectar tu dominio de Cloudflare a Vercel sin intervención manual, necesitas un token de Cloudflare con los permisos adecuados.

1
En Cloudflare: haz clic en tu avatar → My Profile → API Tokens → Create Token.
2
Usa la plantilla personalizada y marca los permisos: Zone (Read) y DNS (Edit).
3
Restringe el token a la zona de tu dominio para mayor seguridad.
4
Copia el token y dáselo a Claude Code con este prompt: "Aquí está mi token de Cloudflare: PASTE_TOKEN. Conecta mi dominio [tudominio.com] a mi proyecto de Vercel y configura los DNS automáticamente."

Ejemplo: Cloudflare pide crear un token API para conectar el dominio a Vercel.

Claude Code ejecuta el despliegue y el redepliegue automáticamente.

✅
Resultado: Claude Code puede añadir los registros A y CNAME en Cloudflare, desactivar temporalmente el proxy mientras Vercel valida el dominio, luego desplegar y redesplegar el sitio automáticamente cada vez que hagas un cambio sin que tengas que intervenir.
⚠️
Seguridad: revoca el token de Cloudflare una vez conectado el dominio. No lo dejes activo innecesariamente.
Consejo: tu nombre personal es el mejor dominio. Sobrevivirá a todos los cambios de posicionamiento.

A recordar

Las 5 reglas para no equivocarte

1. GitHub antes que Vercel

Vercel se conecta a tu cuenta de GitHub. No puedes importar un repo antes de crearlo.

2. Desplegar antes de conectar el dominio

El dominio debe apuntar a un sitio que ya existe. Si no, Vercel no tiene nada que mostrar.

3. Esperar la propagación DNS

Entre añadir los DNS y el momento en que el sitio responde en tu dominio, puede tomar de 5 minutos a varias horas.

4. Probar antes de anunciar

Abre el sitio en el teléfono, haz clic en todos los botones, verifica tu redirección profesional. No compartas un enlace que no funciona.

5. Menos herramientas = menos riesgos

Cada herramienta añadida es un punto de fallo. Empieza con GitHub + Vercel + Cloudflare. Añade el resto solo si realmente lo necesitas.

Los bloqueos más comunes

¿Realmente necesito Claude Code + Ollama?

Puedes usar Claude Code solo o con Ollama/Kimi en local (gratis). La ventaja del local es que todo queda en tu máquina. La ventaja de la nube es potencia y simplicidad: cuenta unos 20 $/mes para esa opción. Si Kimi no está disponible en local, sustitúyelo por un modelo compatible con Ollama como Llama 3 o Mistral.

¿Cómo instalo Claude Code, Ollama y uso Kimi?

1. Claude Code: ve a la documentación oficial https://code.claude.com/docs/en/setup. En Windows, abre un terminal PowerShell y ejecuta este comando:

irm https://claude.ai/install.ps1 | iex

Ejemplo: instalación de Claude Code en un terminal PowerShell de Windows.

2. Añadir Claude Code al PATH: después de la instalación, Windows necesita saber dónde encontrar Claude Code para que puedas lanzarlo desde cualquier carpeta. Si el comando claude no se reconoce, añade su carpeta de instalación a la variable de entorno PATH.

1
Abre el menú Inicio y escribe variables de entorno.
2
Haz clic en Editar las variables de entorno del sistema.
3
En la parte inferior, haz clic en Variables de entorno....
4
En la sección Variables de usuario, selecciona Path y luego haz clic en Editar....
5
Haz clic en Nuevo y pega la ruta donde se instaló Claude Code, por ejemplo: C:\Users\TU_CUENTA\AppData\Local\AnthropicClaude\bin.
6
Confirma con Aceptar en todas las ventanas, luego reinicia PowerShell.
7
Verifica escribiendo: claude --version.

3. Ollama (modelos locales): descarga Ollama desde ollama.com e instálalo. Ollama te permite ejecutar modelos de lenguaje localmente sin enviar tus datos a la nube.

Después de la instalación, verifica que todo esté instalado escribiendo estos dos comandos en PowerShell:

ollama --version claude --version

Si ambos comandos devuelven un número de versión, la instalación es correcta. De lo contrario, verifica PATH o reinstala.

4. Lanzar Claude Code con Ollama: una vez instalado Ollama, abre un terminal PowerShell y lanza Claude Code en modo local con el comando:

ollama launch claude

Este comando inicia Claude Code conectado a tu instancia local de Ollama.

5. Elegir Kimi de la lista: después del lanzamiento, aparece una lista de modelos disponibles. Usa las teclas de flecha ↑ ↓ para bajar en la lista, selecciona Kimi, luego presiona Intro para elegirlo.

Importante: usa las teclas de flecha para bajar y seleccionar Kimi en la lista de modelos.

¿Cloudflare realmente cuesta solo 10 $ al año?

Sí, para un dominio .ca o .com estándar, Cloudflare suele mostrar un precio de unos 10 $ al año (impuestos no incluidos según tu provincia). Vercel, GitHub y Calendly siguen siendo gratuitos en este nivel de uso.

¿Puedo agregar igualmente un formulario de contacto?

Sí. La forma más simple sin backend: un enlace message que abre directamente la app de correo de la visitante con un asunto predefinido. Ejemplo: contacto@tudominio.ca?subject=Solicitud%20de%20contacto. Si quieres un formulario real, puedes añadir un servicio como Formspree más adelante.

¿Cómo vender servicios en línea de forma segura?

La solución más simple y segura es usar un Stripe Payment Link. Creas un enlace de pago en Stripe y luego lo incrustas en un botón de tu sitio. Es rápido, confiable, y no necesitas programar un sistema de pagos.

¿Y si quiero agregar un blog más adelante?

Puedes. Pero empieza con una sola página de inicio. Un blog requiere una estructura más compleja. Una vez que tu sitio funcione, puedes migrar a un generador de sitios estáticos o añadir páginas HTML manualmente.

¿Cuánto tiempo toma realmente?

Si ya tienes tu Business Brain y contenido, el sitio puede estar en línea en un día. Si partes de cero, cuenta 2 a 4 horas por día durante 3 días. La parte técnica (GitHub + Vercel + Cloudflare) solo toma una hora una vez que conoces los pasos.

¿Dónde está el código fuente de mi sitio web?

El código fuente de tu sitio está en tu computadora, en la carpeta del proyecto JavaScript creado por Claude Code. Claude Code ya tiene acceso a él: por eso te pide permiso cada vez que quiere leer o modificar un archivo. Dile Yes, y hace el cambio directamente en tu máquina. Cuando todo está listo, también empuja los archivos a GitHub para ponerlos en línea.
