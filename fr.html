De l'idée au site web.

Une méthode pour construire un site professionnel sur ton propre nom de domaine, sans outil complexe ni automatisation inutile. Tu n'as pas besoin d'être développeuse. Juste de suivre les étapes dans l'ordre.

Le résultat final

Ce qu'on veut construire

Un site web simple, propre et durable. Juste une vitrine qui te représente et qui invite au contact.

Un site sur ton domaine

Un nom de domaine à ton nom ou à ton marque, avec HTTPS activé automatiquement. Le seul coût récurrent : ~10 $ par an chez Cloudflare.

Une page d'accueil claire

Ton message, ton offre, ta bio et un appel à l'action. Le visiteur comprend qui tu es et comment te contacter en quelques secondes.

Une page guide ou ressource

Un PDF ou une page de contenu utile qui montre ton expertise. Le lien est direct.

Pourquoi cette méthode ?

Parce qu'un site efficace n'a pas besoin d'automatisation compliquée.

Tu peux ajouter Calendly pour les réservations, un simple formulaire de contact, ou un lien WhatsApp. Le reste se fait dans la conversation réelle. Moins d'outils = moins de choses qui cassent.

Quel résultat concret tu leur apportes.
3
Comment tu es différente des autres coachs / conseillères.
4
Quels sont tes 1 à 3 services ou offres principales.

2

5

Créer un token GitHub pour Claude Code

Permet à Claude Code de pousser les changements automatiquement.

10 min
Explication simple : un token, c'est une clé que tu donnes à Claude Code pour qu'il puisse modifier ton repo sans que tu ailles sur GitHub à chaque changement.

1
Dans GitHub, va dans Settings → Developer settings → Personal access tokens → Tokens (classic).
2
Clique sur Generate new token (classic).
3
Donne un nom, ex. Claude Code site, et coche la permission repo.
4
Génère le token et copie-le immédiatement.
5
Donne ce token à Claude Code avec ce prompt : "Connecte mon repo GitHub amal-site à Claude Code avec ce token."
✅
Résultat : à chaque modification du code, Claude Code envoie les changements sur GitHub automatiquement. Tu n'as plus besoin de glisser-déposer les fichiers à la main.
🔐
Validation à chaque modification : après avoir donné le token, Claude Code te demandera à chaque fois de valider qu’il peut modifier ton repo sur GitHub. Tu lui dis Yes, et il pousse les changements tout seul. Cela économise beaucoup de casse-tête et tu n’as pas à te connecter manuellement à GitHub à chaque mise à jour.

Créer un compte Vercel

Hébergement gratuit et simple.

5 min
1
Va sur vercel.com/signup.
2
Choisis Continue with GitHub pour lier automatiquement ton compte.

🔗
Pourquoi relier GitHub : quand ton compte Vercel est connecté à GitHub, Vercel peut accéder directement au repo de ton site web. Cela facilite l’importation et le déploiement automatique à chaque modification.
Étape 6.3 : installer l'intégration GitHub dans Vercel
3
Une fois connecté à Vercel, clique sur ton avatar → Settings → Integrations.
4
Vérifie que l’intégration GitHub est installée.
5
Si demandé, autorise Vercel à accéder à tes repositories.

✅
Résultat : Vercel a maintenant la permission de lire le repo de ton site sur GitHub. Sans cette étape, Vercel ne pourra pas importer ton projet.
Étape 6.4 : importer le projet de GitHub vers Vercel
6
Dans Vercel, clique sur Add New → Project.
7
Sélectionne le repo de ton site web (amal-site).
8
Clique sur Import puis sur Deploy.

Après 1 à 2 minutes, tu obtiens un lien temporaire :

https://ton-repo.vercel.app
✅
Ouvre ce lien dans ton navigateur. Tu dois voir ton site.
Étape 6.5 : déploiement automatique via Claude Code avec un token Vercel (optionnel)

Cette méthode permet à Claude Code de créer le projet, brancher le domaine et déclencher le déploiement sans que tu cliques dans l'interface Vercel.

1
Va sur vercel.com/account/tokens.

Va dans Account Settings → Tokens pour créer une nouvelle clé Vercel.

2
Clique sur Create Token et donne-lui un nom, ex. Claude Code deploy.
3
Coche les permissions : Projects (Read/Write), Deployments (Read/Write) et Domains (Read/Write).
4
Copie le token et donne-le à Claude Code avec ce prompt : "Voici mon token Vercel : PASTE_TOKEN. Déploie automatiquement mon site."
5
Claude Code exécute la commande de déploiement Vercel en ligne de commande à ta place. Tu n'as rien à taper toi-même.

Exemple du message que tu recevras quand Vercel a terminé le déploiement.

✅
Résultat : le site est créé et déployé directement depuis la conversation Claude Code. Même si tu n'as pas encore acheté de nom de domaine, Vercel te donne un lien temporaire gratuit, par exemple : https://asmaehajji-website-31dsg1c6k-asmae1.vercel.app/fr. Les prochaines modifications peuvent aussi être poussées et redéployées de la même manière.
La beauté du système

Chaque modification se déploie toute seule.

Grâce aux tokens ajoutés, Claude Code envoie automatiquement chaque changement sur GitHub. Vercel reçoit la mise à jour depuis GitHub et refait le déploiement automatiquement. Tu n'as aucune manipulation manuelle à faire : tout est synchro en arrière-plan.

⚠️
Sécurité : révoque le token Vercel dès que la mise en place est terminée. Ne laisse jamais cette clé active plus longtemps que nécessaire.

Étape 7.5 : connecter Cloudflare et Vercel automatiquement avec un token Cloudflare (optionnel)

Si tu veux que Claude Code configure les enregistrements DNS pour relier ton domaine Cloudflare à Vercel sans intervention manuelle, il te faut un token Cloudflare avec les bonnes permissions.

1
Dans Cloudflare : clique sur ton avatar → My Profile → API Tokens → Create Token.
2
Utilise le modèle personnalisé et coche les permissions : Zone (Read) et DNS (Edit).
3
Limite le token à la zone de ton domaine pour plus de sécurité.
4
Copie le token et donne-le à Claude Code avec ce prompt : "Voici mon token Cloudflare : PASTE_TOKEN. Relie mon domaine [tondomaine.com] à mon projet Vercel et configure les DNS automatiquement."

Exemple : Cloudflare demande la création d'un token API pour connecter le domaine à Vercel.

Claude Code exécute le déploiement et le redeploiement automatiquement.

✅
Résultat : Claude Code peut ajouter les enregistrements A et CNAME dans Cloudflare, désactiver temporairement le proxy le temps que Vercel valide le domaine, puis déployer et redéployer automatiquement le site à chaque modification sans que tu n'aies à intervenir.
⚠️
Sécurité : révoque le token Cloudflare dès que le domaine est branché. Ne le laisse pas actif inutilement.
Conseil : Ton nom personnel est le meilleur domaine. Il survivra à tous les changements de positionnement.

À retenir

Les 5 règles pour ne pas te tromper

1. GitHub avant Vercel

Vercel se connecte à ton compte GitHub. Tu ne peux pas importer un repo avant de l'avoir créé.

2. Déployer avant de brancher le domaine

Le domaine doit pointer vers un site qui existe déjà. Sinon Vercel n'a rien à afficher.

3. Attendre la propagation DNS

Entre l'ajout des DNS et le moment où le site répond à ton domaine, ça peut prendre de 5 minutes à quelques heures.

4. Tester avant d'annoncer

Ouvre le site sur téléphone, clique sur tous les boutons, vérifie ta redirection professionnelle. Ne partage pas un lien qui ne marche pas.

5. Moins d'outils = moins de risques

Chaque outil ajouté est un point de défaillance. Commence avec GitHub + Vercel + Cloudflare. Ajoute le reste seulement si tu en as vraiment besoin.

Les blocages les plus courants

Est-ce que j'ai vraiment besoin de Claude Code + Ollama ?

Tu peux utiliser Claude Code seul ou avec Ollama/Kimi en local (gratuit). L'avantage du local est que tout reste sur ta machine. L'avantage du cloud est la puissance et la simplicité : compte environ 20 $/mois pour cette option. Si Kimi n'est pas disponible localement, remplace-le par un modèle compatible avec Ollama comme Llama 3 ou Mistral.

Comment installer Claude Code, Ollama et utiliser Kimi ?

1. Claude Code : va sur la documentation officielle https://code.claude.com/docs/en/setup. Sous Windows, ouvre un terminal PowerShell et exécute cette commande :

irm https://claude.ai/install.ps1 | iex

Exemple : installation de Claude Code dans un terminal PowerShell Windows.

2. Ajouter Claude Code au PATH : après l'installation, Windows doit savoir où trouver Claude Code pour que tu puisses le lancer de n'importe quel dossier. Si la commande claude n'est pas reconnue, ajoute son dossier d'installation à la variable d'environnement PATH.

1
Ouvre le menu Démarrer et tape variables d'environnement.
2
Clique sur Modifier les variables d'environnement système.
3
En bas, clique sur Variables d'environnement....
4
Dans la section Variables utilisateur, sélectionne Path puis clique sur Modifier....
5
Clique sur Nouveau et colle le chemin où Claude Code a été installé, par exemple : C:\Users\TON_COMPTE\AppData\Local\AnthropicClaude\bin.
6
Valide avec OK sur toutes les fenêtres, puis redémarre PowerShell.
7
Vérifie en tapant : claude --version.

3. Ollama (modèles en local) : télécharge Ollama depuis ollama.com et installe-le. Ollama te permet d'exécuter des modèles de langage localement sans envoyer tes données sur le cloud.

Après l'installation, vérifie que tout est bien installé en tapant ces deux commandes dans PowerShell :

ollama --version claude --version

Si les deux commandes retournent un numéro de version, l'installation est correcte. Sinon, il faut vérifier le PATH ou réinstaller.

4. Lancer Claude Code avec Ollama : une fois Ollama installé, ouvre un terminal PowerShell et lance Claude Code en mode local avec la commande :

ollama launch claude

Cette commande démarre Claude Code connecté à ton instance Ollama locale.

5. Choisir Kimi dans la liste : après le lancement, une liste de modèles disponibles s'affiche. Utilise les flèches du clavier ↑ ↓ pour descendre dans la liste, sélectionne Kimi, puis appuie sur Entrée pour le choisir.

Important : utilise bien les flèches pour naviguer vers le bas et sélectionner Kimi dans la liste des modèles.

Cloudflare coûte vraiment seulement 10 $ par an ?

Oui, pour un domaine .ca ou .com classique, Cloudflare affiche souvent un prix autour de 10 $ par an (hors taxes selon ta province). Vercel, GitHub et Calendly restent gratuits pour ce niveau d'usage.

Je peux quand même ajouter un formulaire de contact ?

Oui. Le moyen le plus simple sans backend : un lien message qui ouvre directement l'application de messagerie de la visiteuse avec un sujet prédéfini. Exemple : contact@tondomaine.ca?subject=Demande%20de%20contact. Si tu veux un vrai formulaire, tu peux ajouter un service comme Formspree plus tard.

Comment vendre des services en ligne de manière sécurisée ?

La solution la plus simple et sécurisée pour vendre des services est d'utiliser un Stripe Payment Link. Tu crées un lien de paiement dans Stripe, puis tu l'imbriques dans un bouton sur ton site. C'est rapide, fiable, et tu n'as pas besoin de coder un système de paiement.

Et si je veux ajouter un blog plus tard ?

Tu peux. Mais commence par une seule page d'accueil. Un blog demande une structure plus complexe. Quand ton site tourne, tu pourras migrer vers un générateur de site statique ou ajouter des pages HTML manuellement.

Combien de temps ça prend vraiment ?

Si tu as déjà ton Business Brain et ton contenu, le site peut être en ligne en une journée. Si tu pars de zéro, compte 2 à 4 heures par jour pendant 3 jours. La partie technique (GitHub + Vercel + Cloudflare) ne prend qu'une heure une fois que tu connais les étapes.

Il est où le code source de mon site web ?

Le code source de ton site est sur ton ordinateur, dans le dossier du projet JavaScript créé par Claude Code. Claude Code y a déjà accès : c’est pour ça qu’il te demande la permission à chaque fois qu’il veut lire ou modifier un fichier. Tu lui dis Yes, et il fait le changement directement sur ta machine. Quand tout est prêt, il pousse aussi les fichiers sur GitHub pour les mettre en ligne.
